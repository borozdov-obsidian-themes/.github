# Borozdov Obsidian Themes

Themes for [Obsidian](https://obsidian.md) by Nikita Borozdov. Each theme lives in its own
repository, ships both a dark and a light face, and is released through Obsidian's community
directory.

## Installing a theme

In Obsidian open Settings → Appearance → Themes → Manage, search for the theme's name,
then choose **Install and use**. Every theme can also be installed by hand from its
repository's latest release.

## Shared ground

- A dark and a light face in every theme, following Obsidian's base color scheme
- No `!important`: any rule can be overridden with a CSS snippet
- No network requests: fonts are embedded or come from the system
- Quiet editing: no focus rings while typing, property names read as labels

Issues and ideas go to the repository of the theme they concern. All themes are MIT-licensed.
