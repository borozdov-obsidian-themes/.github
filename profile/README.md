# Borozdov Obsidian Themes

100 themes for [Obsidian](https://obsidian.md) by Nikita Borozdov — quiet, document-styled, each
in its own repository, each with a dark and a light face, each released through Obsidian's
community theme directory. [borozdov.ru](https://borozdov.ru)

## Installing a theme

In Obsidian: **Settings → Appearance → Themes → Manage** → search for the theme's name →
**Install and use**. Every theme can also be installed by hand from its repository's latest
release (`manifest.json` + `theme.css`).

## Shared ground

- A dark and a light face in every theme, following Obsidian's base color scheme
- No `!important`: any rule can be overridden with a CSS snippet
- No network requests: fonts are embedded or come from the system
- Quiet editing: no focus rings while typing, property names read as labels

Issues and ideas go to the repository of the theme they concern. All themes are MIT-licensed.
